# Results

Experiment outputs are written to `~/tb3_maze_results/` while running. Copy the final versions here to commit them:

- `runs.csv`: every trial (Nav2 planners and DQN), written by `metrics_logger`
- `summary.md`, `summary.csv`, `compare.png`: from `plot_results`
- `map_overlay.png` and the `map_accuracy` printout: SLAM map vs ground truth
- `dqn_training.png`, `dqn_training.csv`: from `plot_dqn_rewards`
